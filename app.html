ℹ️ Sobre o Sistema

Demurrage Manager é um sistema interno desenvolvido para a Transhipping Agenciamento Marítimo Ltda. para centralizar a gestão de Demurrage & Detention (D&D) de containers.


Funcionalidades: controle em tempo real de containers · cálculo automático de D&D em USD · emissão de faturas com QR Code PIX · relatórios Excel · log de auditoria · sistema multiusuário com Supabase.

🗂️ Checkpoints

Checkpoints salvam o estado completo dos dados (BLs, containers, clientes) num ponto no tempo. Um checkpoint automático é criado diariamente ao abrir o sistema. Restaurar substituirá todos os dados atuais.

Acesse a aba Backup para ver os checkpoints.
